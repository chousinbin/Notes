# 家庭网络信息

## 宽带信息

1. 联通 500Mbps 动态公网 IPV4
2. 移动专线

## 公网访问

采用 DDNS + 域名 + 端口号实现公网访问；

- DDNS：DDNS-GO
- 域名：由 CloudFlare 提供 DNS 解析
- 端口号：由主路由器进行端口映射

为了减少端口暴露风险，只暴露一个 OpenVPN 的 UDP 端口；其余内网服务通过 VPN 隧道访问。

## 内网 IP 分配

采用Mac 地址与 IP 绑定的方式；只需要在路由器后台统一管理，不用每个设备单独设置静态 IP。

主路由：192.168.0.1

旁路由：192.168.0.2 [预留]

NAS-eth0：192.168.0.3

NAS-eth1：192.168.0.4 [预留]

监控：192.168.0.5

大厅外网机：192.168.0.10

大厅专线机：192.168.0.11

Mac：192.168.0.12
